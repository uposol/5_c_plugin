# 5ch 阅读优化 · Loon

将提供的两个 5ch 篡改猴脚本合并为一个 Loon 插件，面向 **Loon 3.5.2(1005)**，采用新版条件 Rewrite / Script 语法。

## 安装

在 Loon 的插件页面添加：

https://raw.githubusercontent.com/uposol/5_c_plugin/main/5ch_Reading.plugin

启用 MitM，安装并信任 Loon 证书。插件会自动引用同仓库的 `5ch_Reading.response.js`，不需要单独添加 JS。建议关闭原来的两个篡改猴脚本，避免重复执行。更新后刷新帖子页面；已打开的页面需要重新加载。

## 功能与开关

三个开关默认开启：

- **跳转 l- 页面**：仅将 itest 的裸帖子地址跳到 `/l-`，保留查询参数；已有 `/l-`、指定楼层等范围保持原样。
- **移除乱码和重复帖**：沿用原脚本判定。去空白、全角英文字母转换后，长度至少 200，大写字母占比至少 80%，日文字符不超过 2，且至少 5 个 `<br>` 或连续至少 80 个大写字母，才算大写乱码。相同正文同页出现第 6 次时整组移除；后续相同正文继续移除。比较正文时忽略回复楼层链接与空白。
- **移除正文含 ◆ 的帖子**：只检查正文，短正文同样适用；用户名中的 tripcode 不作为依据。

覆盖 `itest.5ch.io/<服务器>/test/read.cgi/<板块>/<帖子>` 和 `*.5ch.io/test/read.cgi/<板块>/<帖子>` 的 HTTPS HTML 页面。支持原脚本使用的移动端 `li.threadview_response` 和桌面端 `div.post`。页面动态追加或修改帖子时，延迟 200ms 重新检查。

## 实现与限制

插件入口与 JS 合计约 **9.5 KiB**。Loon 仅负责窄范围跳转及 HTML 注入，DOM 判断在网页里运行；不包含广告列表或全站大正则，也不发送帖子内容到第三方。网页正文需要经过 Loon 响应脚本缓冲，这是 HTML 注入本身的开销。无关 DOM 变动不触发扫描。

遇到 CSP 响应头时只授权注入脚本的确切 SHA-256 哈希，保留其他限制。过滤关闭后不注入；错误时保留原响应。与其他同一 URL 的响应脚本存在优先级竞争时，按 Loon 的脚本匹配顺序执行；需要避免其他插件抢先处理该页面。

已通过隔离 Chrome 合成页面的动态 DOM、阈值、重复帖、各开关和跳转测试，以及响应注入/CSP 检查。**尚未在 iPhone Loon 真机上验证**。真实站点改版、非原脚本支持的 DOM、沙箱 CSP 或浏览器限制可能影响效果。

## 来源
